🤖 Автоторговля (Return-паттерны)

ВЫКЛ
Логика: при закрытии второй свечи Return-паттерна (rising → SELL, falling → BUY) открывается позиция. Выход — при касании текущей ценой цели open2 второй свечи (rising → BUY, falling → SELL). Открытая позиция — одна. Проверка при каждом обновлении свечей. «Требовать MTF-подтверждение» — вход только если есть хотя бы один другой ТФ с подтверждающим Return-паттерном.
